AI models used by BlockML Studio (served from this folder):

- face-detector, face-mesh: MediaPipe face_detection (short) and
  face_landmarks_detection (face_mesh), TF.js versions — Apache License 2.0
- hand-detector-lite, hand-landmarks-lite: MediaPipe handpose_3d (lite),
  TF.js versions — Apache License 2.0
- movenet-lightning: Google MoveNet SinglePose Lightning v4, TF.js version —
  Apache License 2.0
- mobilenet-v2: Google MobileNet V2 (1.0, 224) ImageNet classification, TF.js
  version — Apache License 2.0 (used for its image features)
- coco-ssd-lite: COCO-SSD (SSDLite MobileNet v2), TF.js version from
  tfjs-models — Apache License 2.0
- vosk-small-en: Vosk vosk-model-small-en-us-0.15 (Alpha Cephei,
  alphacephei.com/vosk/models), repacked as a split .tar.gz for the browser —
  Apache License 2.0
- ocr-eng: Tesseract "tessdata_fast" English model (eng.traineddata, gzipped),
  github.com/tesseract-ocr/tessdata_fast — Apache License 2.0
- text-potion: Model2Vec "potion-base-8M" static text embeddings (Minish Lab,
  huggingface.co/minishlab/potion-base-8M), repacked as one byte per number —
  MIT License, Copyright (c) 2024 Thomas van Dongen (see below).
  kindness.bin in the same folder is BlockML Studio's own kindness check (MIT),
  trained on the Civil Comments dataset (Jigsaw / Google, CC0) and the sentences
  in scripts/kindness-phrases.mjs; it contains only learned numbers, no comments.
